# HEART · 목표–신호–지표 · SUS

출처: Kerry Rodden·Hilary Hutchinson·Xin Fu「Measuring the User Experience on a Large Scale: User-Centered Metrics for Web Applications」(CHI 2010, Google), Jeff Sauro「Measuring Usability with the System Usability Scale (SUS)」(MeasuringU, 2011), John Brooke「SUS: A quick and dirty usability scale」(1996), NN/g Budiu·Moran「How Many Participants for Quantitative Usability Studies」(2021). 요약이다.

## 1. HEART

| 범주         | 뜻                           | 신호 예                     | 지표 예                                             |
| ------------ | ---------------------------- | --------------------------- | --------------------------------------------------- |
| Happiness    | 태도 — 만족, 쉬움, 추천 의향 | 설문 응답                   | 기능 사용 직후 만족도 4점 이상(5점 척도) 응답 비율  |
| Engagement   | 사용자당 빈도·강도·깊이      | 주간 방문, 세션당 작업 수   | 활성 사용자당 주간 작업 수                          |
| Adoption     | 기간 안의 새 사용자          | 기능 첫 사용                | 7일 안에 처음 쓴 활성 사용자 비율                   |
| Retention    | 나중에도 계속 쓰는 사용자    | 재사용                      | 첫 사용 뒤 30일 안 재사용 비율                      |
| Task success | 효율·효과·오류               | 완료, 포기, 오류, 걸린 시간 | 시작 대비 완료율, 완료까지 걸린 시간 중앙값, 오류율 |

- 다섯 범주를 모두 쓸 필요는 없다. 넣고 빼는 이유를 적는다.
- 집계는 사용자당 비율이나 평균으로 한다. 원수는 사용자가 늘면 저절로 오른다.
- 신호는 목표가 움직일 때만 움직이는 것을 고른다. 포기·되돌리기·재시도처럼 실패를 나타내는 신호는 잡기 쉽고 정직하다.

## 2. 목표 → 신호 → 지표 쓰는 순서

1. 목표: 「사용자가 막힘 없이 노트를 공유한다」 — 측정 가능성은 아직 따지지 않는다.
2. 신호: 공유 시작, 공유 완료, 공유 취소, 공유 중 오류.
3. 지표: 「주간, 공유를 시작한 사용자 중 완료한 사용자 비율」 — 분모·기간·단위를 쓴다.

## 3. 가드레일 예

| 바꾸는 것 | 가드레일                                                        |
| --------- | --------------------------------------------------------------- |
| 해지 흐름 | 해지 관련 문의 수(사용자당), 환불 요청, 해지 완료까지 걸린 시간 |
| 가입 흐름 | 가입 뒤 7일 안 이탈, 고객 문의, 오류율                          |
| 추천·피드 | 숨기기·신고 비율, 세션당 되돌아가기                             |
| 성능 변경 | 주요 화면 응답 시간 p75                                         |
| 모든 변경 | 접근성 문제 신고, 오류율                                        |

## 4. SUS (System Usability Scale)

- 10문항, 5점 척도. 검증된 번역본을 쓴다 — 문항을 임의로 바꾸면 점수를 비교할 수 없다.
- 점수: 홀수 문항은 (응답 − 1), 짝수 문항은 (5 − 응답). 합계 × 2.5 = 0~100점. 백분율이 아니다.
- 해석: 68점이 평균(C), 74점은 약 상위 30%, 80.3점 넘으면 A(상위 10%), 51점 미만은 F.
- 정량으로 비교하려면 표본이 필요하다 — 정량 사용성 연구는 40명(신뢰수준 95%·오차 15%) 기준, 위험이 낮으면 28명(90%·15%)이나 15명(90%·20%).

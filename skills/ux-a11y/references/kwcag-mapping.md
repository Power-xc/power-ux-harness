# 국내 접근성 지침 대조

출처: 한국형 웹 콘텐츠 접근성 지침 2.2(KS X OT0003:2022, 2022-12-28 개정, 방송통신표준심의회·국립전파연구원, 한국지능정보사회진흥원 안내), 모바일 애플리케이션 콘텐츠 접근성 지침(KS X 3253:2025, 2025-12-31 개정 2판, 국립전파연구원 표준 열람). 검사 항목 이름은 원문 표기를 따랐고 설명은 요약했다. 인증 심사 기준의 적용 시점은 인증 기관 공지로 확인한다.

## 1. KWCAG 2.2 개요

- 4원칙 · 14지침 · 33검사 항목(2.1은 24개).
- 2.2에서 새로 생긴 검사 항목 9개와 대응하는 WCAG 기준:

| KWCAG 2.2                   | 대응 WCAG                                             |
| --------------------------- | ----------------------------------------------------- |
| 6.1.4 문자 단축키           | 2.1.4 Character Key Shortcuts                         |
| 6.4.4 고정된 참조 위치 정보 | 대응 기준 없음(전자출판 형식의 페이지 이동·위치 정보) |
| 6.5.1 단일 포인터 입력 지원 | 2.5.1 Pointer Gestures                                |
| 6.5.2 포인터 입력 취소      | 2.5.2 Pointer Cancellation                            |
| 6.5.3 레이블과 네임         | 2.5.3 Label in Name                                   |
| 6.5.4 동작기반 작동         | 2.5.4 Motion Actuation                                |
| 7.2.2 찾기 쉬운 도움 정보   | 3.2.6 Consistent Help                                 |
| 7.3.3 접근 가능한 인증      | 3.3.8 Accessible Authentication (Minimum)             |
| 7.3.4 반복 입력 정보        | 3.3.7 Redundant Entry                                 |

## 2. 자주 쓰는 검사 항목

| KWCAG 2.2                       | 확인할 것                                                    | 메모                                                      |
| ------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------- |
| 5.4.3 텍스트 콘텐츠의 명도 대비 | 글자 대비 4.5:1 이상                                         | WCAG 1.4.3과 같은 기준                                    |
| 6.1.3 조작 가능                 | 컨트롤 대각선 6.0mm 이상, 컨트롤 안쪽 1px 이상의 비활성 여백 | 권장 성격 — WCAG 2.5.8(24 CSS px)과 함께 적는다           |
| 6.2.1 응답시간 조절             | 시간 제한을 없애거나 늘릴 수 있고, 끝나기 20초 전에 알린다   | 스스로 사라지는 알림 점검에 함께 쓴다                     |
| 8.1.1 마크업 오류 방지          | 마크업 문법 오류가 없다                                      | WCAG 2.2에서는 4.1.1이 삭제됐지만 KWCAG 2.2에는 남아 있다 |

## 3. 모바일 앱 — KS X 3253:2025

- WCAG 2.2(ISO/IEC 40500:2025)의 A·AA를 바탕으로 4원칙 · 13지침 · 41검사 항목(신규 23개).
- 자주 쓰는 항목:

| 항목                  | 확인할 것                                           |
| --------------------- | --------------------------------------------------- |
| 6.1.2                 | 터치 대상 24×24px 이상(운영체제 표준 컨트롤 제외)   |
| 5.3.4                 | 화면 방향을 한쪽으로 고정하지 않는다                |
| 5.4.5 · 5.4.7 · 5.4.8 | 글자 200% 확대, 재배치, 글자 간격 조절              |
| 6.5.1~6.5.4           | 포인터·동작 입력 대안                               |
| 7.2.3                 | 도움말이 화면마다 같은 자리에 있다                  |
| 7.3.3~7.3.5           | 오류 예방, 반복 입력 없음, 접근 가능한 인증         |
| 8.1.2                 | 상태 메시지를 포커스 이동 없이 화면 낭독기에 알린다 |

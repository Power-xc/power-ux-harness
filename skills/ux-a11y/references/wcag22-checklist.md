# WCAG 2.2 AA 점검표

출처: W3C「Web Content Accessibility Guidelines (WCAG) 2.2」(권고안 2023-10-05, 현행판 2024-12-12, ISO/IEC 40500:2025로도 승인), W3C WAI「What's New in WCAG 2.2」, Understanding SC 2.2.1(2026 갱신)·4.1.3(2026 갱신), W3C WCAG 3.0 작업 초안(2026-09-10)과 WAI 소개 페이지, Apple HIG Accessibility·Buttons, Material Design 3 접근성(구조). 기준 이름은 W3C 원어를 함께 적었다.

## 1. 2.2에서 새로 생긴 기준

| 기준                                      | 수준 | 확인할 것                                                                                                                                                                       |
| ----------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.4.11 Focus Not Obscured (Minimum)       | AA   | 포커스 받은 요소가 고정 헤더·쿠키 배너·채팅 버튼·토스트에 **완전히** 가려지지 않는다                                                                                            |
| 2.4.12 Focus Not Obscured (Enhanced)      | AAA  | 일부도 가려지지 않는다                                                                                                                                                          |
| 2.4.13 Focus Appearance                   | AAA  | 포커스 표시가 2 CSS px 윤곽 넓이 이상, 전후 대비 3:1 이상                                                                                                                       |
| 2.5.7 Dragging Movements                  | AA   | 끌어서 하는 일을 한 번 누르기로도 할 수 있다(끌기가 꼭 필요한 경우 제외)                                                                                                        |
| 2.5.8 Target Size (Minimum)               | AA   | 대상이 24×24 CSS px 이상. 작으면 대상 중심에 그린 24px 원이 다른 대상·원과 겹치지 않아야 한다. 같은 기능의 다른 대상, 문장 안 링크, 브라우저 기본 컨트롤, 꼭 필요한 경우는 예외 |
| 3.2.6 Consistent Help                     | A    | 연락처·문의 양식·도움말·챗봇이 페이지마다 같은 상대 순서에 있다                                                                                                                 |
| 3.3.7 Redundant Entry                     | A    | 같은 과정에서 입력한 정보를 다시 묻지 않고 자동으로 채우거나 고르게 한다                                                                                                        |
| 3.3.8 Accessible Authentication (Minimum) | AA   | 기억·옮겨 적기·퍼즐 같은 인지 시험만으로 로그인하게 하지 않는다. 붙여 넣기·비밀번호 관리자를 허용한다                                                                           |

4.1.1 Parsing은 2.2에서 삭제됐다. 2.0·2.1을 따르는 기관은 여전히 보고해야 할 수 있다.

## 4. WCAG 3에 대해

WCAG 3.0은 작업 초안이고 몇 년 안에 완성될 예정이 아니다. 지금은 WCAG 2.2를 기준으로 하고, WCAG 3 적합을 주장하지 않는다.

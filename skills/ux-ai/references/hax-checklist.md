# HAX 18개 지침 점검표

출처: Saleema Amershi 외「Guidelines for Human-AI Interaction」(CHI 2019, Microsoft HAX Toolkit), Google PAIR「People + AI Guidebook」, Apple Human Interface Guidelines「Generative AI」(2025, 2026 갱신). 지침 이름은 원문 뜻을 살려 옮겼고 확인 질문은 이 저장소에서 썼다.

## 처음

| #   | 지침                       | 화면에서 확인할 것                                     |
| --- | -------------------------- | ------------------------------------------------------ |
| H1  | 무엇을 할 수 있는지 분명히 | 첫 사용·빈 상태에서 할 수 있는 일과 예시를 보여 주는가 |
| H2  | 얼마나 잘하는지 분명히     | 틀릴 수 있다는 사실과 잘 못하는 일을 알리는가          |

## 쓰는 동안

| #   | 지침               | 화면에서 확인할 것                               |
| --- | ------------------ | ------------------------------------------------ |
| H3  | 맥락에 맞는 때     | 사용자가 다른 일에 집중할 때 끼어들지 않는가     |
| H4  | 맥락에 맞는 정보   | 지금 과제와 관련된 결과만 보여 주는가            |
| H5  | 사회적 규범에 맞게 | 말투·호칭이 사용자와 상황에 맞는가               |
| H6  | 사회적 편향 줄이기 | 성별·나이·지역에 대한 고정관념을 강화하지 않는가 |

## 틀렸을 때

| #   | 지침                      | 화면에서 확인할 것                             |
| --- | ------------------------- | ---------------------------------------------- |
| H7  | 쉽게 불러내기             | 필요할 때 바로 부를 수 있는가                  |
| H8  | 쉽게 물리치기             | 원치 않는 제안을 쉽게 닫거나 무시할 수 있는가  |
| H9  | 쉽게 고치기               | 결과를 고치거나 고쳐 물을 수 있는가            |
| H10 | 확신이 낮으면 범위 좁히기 | 모를 때 지어내지 않고 범위를 좁히거나 되묻는가 |
| H11 | 왜 그렇게 했는지 설명     | 추천·결과의 이유나 출처를 볼 수 있는가         |

## 시간이 지나며

| #   | 지침               | 화면에서 확인할 것                                 |
| --- | ------------------ | -------------------------------------------------- |
| H12 | 최근 상호작용 기억 | 방금 한 일을 다시 설명하게 하지 않는가             |
| H13 | 행동에서 배우기    | 사용자의 선택이 이후 결과에 반영되는가(알리면서)   |
| H14 | 조심스럽게 바꾸기  | 갑작스러운 동작 변화로 사용자를 놀라게 하지 않는가 |
| H15 | 자세한 피드백 받기 | 좋아요·싫어요 외에 이유를 남길 수 있는가           |
| H16 | 행동의 결과 알리기 | 사용자의 피드백·설정이 무엇을 바꾸는지 보여 주는가 |
| H17 | 전체 통제          | AI 기능 끄기, 기억·개인화 초기화가 있는가          |
| H18 | 변화 알리기        | 기능·동작이 바뀌면 알리는가                        |

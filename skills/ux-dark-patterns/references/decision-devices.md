# 결정 장치 — 정직한 쓰임과 기만의 경계

출처: 행동경제학의 널리 알려진 개념(앵커링·손실 회피·기본값 효과·사회적 증거·희소성·프레이밍·선택 과부하·피크엔드 법칙·자이가르닉 효과)을 Jon Yablonski『Laws of UX』(2판, 2024)와 공정위 가이드라인(2026)의 유형에 맞춰 이 저장소에서 정리했다.

같은 장치도 사실에 근거하면 결정을 돕고, 사실이 아니거나 사용자의 이익에 반하면 기만이다. 경계를 넘으면 P1이다.

| 장치          | 정직한 쓰임                                   | 기만으로 넘어가는 선                                                |
| ------------- | --------------------------------------------- | ------------------------------------------------------------------- |
| 앵커링        | 실제로 팔았던 정가와 할인가를 함께 보여 준다  | 판매한 적 없는 가격을 정가로 표시                                   |
| 손실 회피     | 실제로 만료되는 혜택의 기한을 알린다          | 끝나면 다시 시작하는 마감 시계 · 해지 화면의 과장된 「모두 잃어요」 |
| 기본값        | 대부분에게 맞는 안전한 설정을 기본값으로 둔다 | 유료 옵션·마케팅 동의·추가 상품을 미리 선택                         |
| 사회적 증거   | 실제 집계한 후기·이용자 수를 출처와 함께      | 지어낸 「지금 N명이 보는 중」 · 불리한 후기 숨김                    |
| 희소성        | 실제 재고·좌석 수                             | 새로고침해도 줄지 않는 「남은 2석」                                 |
| 프레이밍      | 같은 수치를 결정에 도움 되는 쪽으로 표현      | 불리한 조건을 작은 글씨나 다른 단위로 숨김                          |
| 선택지 줄이기 | 추천 하나를 강조하되 전체 보기를 남긴다       | 비싼 선택지만 남기고 나머지를 숨김                                  |
| 피크엔드      | 완료 화면과 오류 복구 화면에 공을 들인다      | —                                                                   |
| 미완료 효과   | 남은 단계를 보여 줘 끝내기를 돕는다           | 끝나지 않는 진행률로 계속 붙잡음                                    |

## 판정 질문

1. 그 숫자·문구는 사실인가, 출처를 댈 수 있는가.
2. 사용자가 장치를 알아챘을 때 속았다고 느낄까.
3. 거절하거나 되돌리는 길이 수락하는 길만큼 쉬운가.
4. 이 장치가 없으면 사용자의 결정이 달라지는가 — 달라진다면 그 결정이 사용자에게 이로운가.

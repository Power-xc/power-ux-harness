# 해외 기준 — EU·미국·유형 사전

출처: EU Regulation (EU) 2022/2065 Digital Services Act 제25조와 전문 67, European Parliament Legislative Train「Digital Fairness Act」(2026-09 갱신)·EPRS 브리핑(2026-10), 미국 FTC 직원 보고서「Bringing Dark Patterns to Light」(2022-09), 미국 제8순회항소법원 Custom Communications v. FTC(2025-07-08), FTC 네거티브 옵션 규칙 사전 공고(2026-03-11), deceptive.design 유형 목록(Harry Brignull). 요약이며 법률 자문이 아니다. 진행 중인 입법은 판정 시점의 상태를 다시 확인한다.

## 1. EU

**DSA 제25조** — 온라인 플랫폼은 이용자를 속이거나 조작하는 방식, 자유롭고 충분한 정보에 근거한 결정을 크게 해치는 방식으로 인터페이스를 설계하면 안 된다. 소비자 보호 지침·GDPR이 이미 다루는 관행은 제외된다. 집행위원회가 지침을 낼 수 있는 세 관행:

| 관행                                    | 점검 질문                           |
| --------------------------------------- | ----------------------------------- |
| 특정 선택지를 더 두드러지게             | 수락·거절의 크기·색·위치가 대등한가 |
| 이미 한 선택을 반복해서 묻기(특히 팝업) | 거절 뒤 같은 요구가 다시 뜨는가     |
| 가입보다 어려운 해지                    | 해지 단계·경로가 가입과 대등한가    |

전문 67은 바꾸기 어려운 기본 설정도 예로 든다.

**Digital Fairness Act** — 아직 제안 전이다(2026-10 기준, 2026년 11월 중순 제안 예정으로 보도). 다크패턴, 중독적 설계(자동 재생·무한 스크롤·보상 장치), 구독 해지·갱신, 불공정한 개인화, 인플루언서 마케팅, 개인화 가격이 범위로 거론된다. 판정에 쓰기 전에 현재 상태를 확인한다.

## 2. 미국

**FTC「Bringing Dark Patterns to Light」(2022)** — 네 범주:

| 범주                        | 예                                |
| --------------------------- | --------------------------------- |
| 거짓 믿음 만들기            | 가짜 후기·가짜 희소성·가짜 긴급성 |
| 중요한 정보 숨기거나 늦추기 | 단계마다 붙는 수수료(드립 가격)   |
| 승인하지 않은 결제로 이끌기 | 무료 체험 뒤 고지 없는 자동 결제  |
| 개인정보 선택 흐리기        | 최대 수집이 기본값, 모호한 토글   |

보고서의 권고: 필수 수수료는 처음 보이는 가격에 넣는다. 동의는 사용자의 의도적 행동으로 받는다. 해지는 가입과 같은 곳에서 적어도 가입만큼 쉽게, 해지를 늦추는 붙잡기 제안 없이. 개인정보 기본값을 최대 수집으로 두지 않는다.

**클릭 해지(click-to-cancel) 규칙** — 2024년 규칙은 2025-07-08 항소법원 판결로 효력을 잃었고, FTC는 2026-03-11 새 규칙 제정을 위한 의견 수렴을 시작했다. 이후 상태는 확인이 필요하다. 주(州)별 자동 갱신 법은 별도로 확인한다.

## 3. 유형 사전 (deceptive.design)

국내 유형과 짝지어 쓴다. 영어 이름은 보고서의 해외 독자를 위해 함께 적는다.

| 유형                  | 뜻                  | 가까운 국내 유형                    |
| --------------------- | ------------------- | ----------------------------------- |
| Sneaking              | 몰래 담기·숨겨 넣기 | 특정옵션의 사전선택                 |
| Hidden costs          | 마지막에 붙는 비용  | 순차공개 가격책정                   |
| Hidden subscription   | 숨은 정기결제       | 숨은갱신                            |
| Hard to cancel        | 어려운 해지         | 취소·탈퇴 등의 방해                 |
| Obstruction           | 일부러 어렵게       | 취소·탈퇴 등의 방해 · 가격비교 방해 |
| Preselection          | 미리 선택           | 특정옵션의 사전선택                 |
| Visual interference   | 시각적 방해         | 잘못된 계층구조                     |
| Trick wording         | 속임수 문구         | 속임수 질문                         |
| Nagging               | 끈질긴 요구         | 반복간섭                            |
| Fake scarcity         | 가짜 희소성         | 유인 판매 · 숨겨진 정보             |
| Fake urgency          | 가짜 긴급성         | —                                   |
| Fake social proof     | 가짜 사회적 증거    | 거짓 추천                           |
| Disguised ads         | 위장 광고           | 위장 광고                           |
| Confirmshaming        | 죄책감 주는 거절    | —                                   |
| Forced action         | 강요된 행동         | —                                   |
| Comparison prevention | 비교 방해           | 가격비교 방해                       |
| Currency confusion    | 화폐·포인트 혼동    | 숨겨진 정보                         |
| Addictive design      | 중독적 설계         | —                                   |

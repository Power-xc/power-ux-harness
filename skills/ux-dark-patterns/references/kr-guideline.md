# 국내 다크패턴 기준 — 13개 유형

출처: 공정거래위원회「다크패턴 방지를 위한 온라인 인터페이스 운영 가이드라인」(2026-10-06 배포, 공공누리 제1유형), 「전자상거래 등에서의 소비자보호에 관한 법률」(다크패턴 조항 2025-02-14 시행)과 시행령, 공정위 보도자료(2025-09-30 모니터링 결과, 2025-10-15 구독 서비스 제재, 2026-06-09 회원가 표시 제재). 앱 마켓 정책은 Google Play 고객센터「Understanding Google Play's app account deletion requirements」와 Apple「App Review Guidelines」5.1.1(v)(둘 다 2026-11-03 확인). 가이드라인의 정의와 준수사항을 점검 질문으로 요약했다. 법률 자문이 아니다.

## 2. 법정 6개 유형의 점검 질문

### 숨은갱신

- 금액 인상이나 유료 전환 **30일 전까지** 일시·변동 전후 가격·결제 방법에 대해 별도 동의를 받는가(시행령 §20의2).
- 취소·해지 조건과 방법, 그 효과를 알리는가.
- 기간 한정 할인·무료 이용이 끝나 실제 지불액이 늘어나는 경우도 동의 대상으로 다루는가.
- 응답이 없는 것을 동의로 처리하지 않는가.

### 순차공개 가격책정

- 가격을 처음 보여 주는 화면(검색 결과·상품 목록 포함)에 배송비·설치비·현장 결제비처럼 거부할 수 없는 비용을 포함한 **총금액**이 있는가.
- 공간이 좁으면 첫 화면과 바로 연결된 화면에서 알리는가.

### 특정옵션의 사전선택

- 구매·가입과 관련한 선택 항목(추가 상품·보험·유료 옵션·마케팅 동의)이 미리 선택돼 있지 않은가.
- 직전 배송지처럼 단순 편의를 위한 기본값은 이 유형과 구분해 판단한다.

### 잘못된 계층구조

- 선택지 사이에 크기·모양·색의 현저한 차이가 있는가 — 수락은 큰 채운 버튼, 거절은 흐린 작은 글자인 경우.
- 측정해서 적는다: 두 선택지의 크기(px), 글자 크기, 대비.

### 취소·탈퇴 등의 방해

- 가입·구매와 **같은 방법**(같은 앱·웹)으로 해지할 수 있는가. 전화·이메일·방문·상담 게시판·챗봇으로만 받지 않는가.
- 해지 절차의 클릭 수·메뉴 수가 가입보다 많지 않은가.
- 해지 버튼이 **로그인한 첫 화면이나 거기서 한 번 이동한 화면**(예: 마이페이지·계정 관리)에 있는가. 「개인정보 수정」·「보안 설정」처럼 예측하기 어려운 곳에 숨기지 않았는가.
- 버튼 이름이 「멤버십 해지」·「회원 탈퇴」처럼 바로 알아볼 수 있는가.
- 혜택 상실 안내 → 의사 재확인 → 다시 재확인처럼 의사를 반복해 묻지 않는가.
- 해지 이유 설문에 응답을 강제하지 않는가.
- 탈퇴 뒤 되돌리기·유예 기간이 있으면 기간과 끝나는 날짜(「11월 30일까지 되돌릴 수 있어요」)를 함께 보이는가. 「30일 뒤 삭제돼요」만 있으면 사용자가 날짜를 계산해야 한다. 서버가 날짜를 모르면 지어내지 않고 기간만 적는다.
- 앱이면 마켓 정책도 대조한다 — 계정을 만들 수 있는 앱은 앱 안에서 계정 삭제를 시작할 수 있어야 하고(두 마켓 공통), Google Play는 앱을 다시 설치하지 않고 쓸 수 있는 웹 삭제 요청 링크(앱·개발자 이름 표시)와 남기는 데이터·기간 안내도 요구한다. 어긋나면 다크패턴 유형과 따로 「마켓 정책」으로 적는다.
- 본인 확인·정산·법정 절차처럼 정당한 사유가 있으면 그 사유를 적는다.

### 반복간섭

- 이미 거절한 선택을 다시 묻지 않는가(두 번 이상 같은 질문 금지).
- 번복을 권하는 팝업에 「7일간 다시 보지 않기」처럼 **최소 7일** 같은 요구를 받지 않는 선택지가 있는가.
- 거절 버튼이 따로 없다면 팝업을 닫는 것을 거절로 처리하는가.

## 3. 나머지 7개 유형의 점검 질문

| 유형          | 점검 질문                                                                                                             |
| ------------- | --------------------------------------------------------------------------------------------------------------------- |
| 거짓 할인     | 할인 전 기준가격이 실제로 판매한 가격인가, 할인율 계산이 맞는가, 한 번 쓰는 쿠폰가를 상시 가격처럼 보이게 하지 않는가 |
| 거짓 추천     | 불리한 후기를 숨기지 않는가, 후기의 정렬·노출 기준을 밝히는가                                                         |
| 유인 판매     | 재고가 없는 상품을 판매 중으로 표시하지 않는가                                                                        |
| 위장 광고     | 대가를 받은 콘텐츠·검색 상단 노출에 광고 표시가 있는가                                                                |
| 속임수 질문   | 이중 부정·뒤집힌 체크박스(「받지 않으려면 체크」)가 없는가, 한 질문이 한 가지 뜻인가                                  |
| 숨겨진 정보   | 제한 사항·위약금·자동 갱신 같은 중요 정보가 결정 화면에서 읽을 수 있는 크기로 보이는가                                |
| 가격비교 방해 | 단위 가격·총액을 같은 기준으로 보여 주는가, 옵션마다 다른 단위로 표시하지 않는가                                      |

## 4. 집행 흐름

- 2025-09: 공정위 모니터링에서 36개 사업자의 의심 사례 45건을 확인했고 34건이 자진 시정됐다.
- 2025-10: 구독 서비스 사업자들에 시정명령·과태료 — 멤버십 가격 인상 동의를 유도한 팝업, 중도 해지 가능 사실 미고지 등.
- 2026-06: 한 번 쓰는 쿠폰가를 상시 회원가처럼 표시한 행위에 과징금.
- 2026-10: 13개 유형을 통합한 가이드라인 배포.

보고서에는 회사 이름이 아니라 유형과 화면 위치로 적는다.

# 합성 페르소나 규칙

출처: Park 외「Generative Agent Simulations of 1,000 People」(arXiv 2411.10109, 2024; v3 2026), Li 외「LLM Generated Persona is a Promise with a Catch」(NeurIPS 2025), Wang 외「Large language models that replace human participants can harmfully misportray and flatten identity groups」(Nature Machine Intelligence, 2025), Peng 외「Digital twins are funhouse mirrors」(Science Advances, 2026), NVIDIA「Nemotron-Personas-Korea」 데이터셋 카드(Hugging Face, 2026). 요약이고 규칙은 이 저장소에서 정했다.

## 1. 원칙

- **구조화된 속성에서 뽑는다.** 실제 자기 보고(인터뷰 녹취)에 근거한 페르소나가 가장 정확하고, 모델이 길게 써 준 페르소나 서술일수록 결과가 긍정적이고 한쪽으로 치우친다. 서술은 읽기 쉽게 하는 색깔로만 쓰고, 배경 이야기를 모델이 더 지어내게 하지 않는다.
- **집단 이름표로 정의하지 않는다.** 「60대」·「대학생」 같은 이름표만 주면 모델은 그 집단을 바깥에서 본 고정관념으로 그리고 집단 안의 다양성을 지운다. 과제, 상황, 제약, 과거 행동으로 정의한다.
- **개인 수준 정확도를 믿지 않는다.** 합성 응답은 사람보다 퍼짐이 작고, 인구통계만 준 경우보다 크게 낫지 않을 때가 많다. 페르소나는 서로 다른 관점을 펼쳐 보는 도구이고, 실제 사람의 대리인이 아니다.

## 2. 구성

| 역할              | 인원 | 왜                                                                  |
| ----------------- | ---- | ------------------------------------------------------------------- |
| 핵심 대상         | 1~2  | 결정이 가장 많이 닿는 사용자                                        |
| 접근성·경계       | 1    | 저시력·화면 낭독기·고령·한 손 사용·느린 네트워크 중 결정과 닿는 것  |
| 회의적            | 1    | 바꾸기 싫어하고 의심이 많아 반대 의견을 낼 사람                     |
| 기준선(보고 제외) | 2    | 빈 페르소나, 인구통계만 있는 페르소나 — 페르소나 효과를 재는 비교군 |

## 3. 페르소나 카드 양식

```markdown
### P2 · 글자를 키워 쓰는 독자

| 속성             | 값                                    | 근거                       |
| ---------------- | ------------------------------------- | -------------------------- |
| 과제             | 다음 결제 전에 구독을 해지하려 함     | S1 4장                     |
| 상황             | 시스템 글자 크기 최대, 저녁에 휴대폰  | S3 리뷰 분류 「글자 작음」 |
| 나이대           | 60대                                  | 인구 데이터 uuid 3f2a…     |
| 과거 행동        | 해지 메뉴를 찾다 고객센터에 전화한 적 | `가정`                     |
| 이 결정에서 걱정 | 해지하면 남은 기간이 사라지는지       | S3 「남은 기간 모름」 21건 |
```

- 근거 칸이 빈 속성은 없어야 한다. 근거가 없으면 `가정`이라고 쓴다.
- `가정`이 절반을 넘는 페르소나는 결과 해석에서 비중을 낮추고 그 사실을 적는다.

## 4. 인구 데이터 쓰기

실제 사용자 데이터(인터뷰·설문·문의 기록)가 있으면 그것이 먼저다. 없을 때 국내 대상이면 Nemotron-Personas-Korea를 쓸 수 있다.

- 내용: 19세 이상 100만 레코드(레코드마다 서술 7종), 시도·시군구·나이·성별(sex)·혼인·가구 형태·주거·학력·직업 등. 통계청·대법원·국민건강보험공단 등 공개 통계 분포에 맞춰 합성했다. 라이선스 CC BY 4.0 — 쓰면 출처를 밝힌다.
- 뽑는 법: 결정과 관련된 속성 2~3개로 쿼터를 정해 층화 추출하고, seed와 쿼터를 기록하고, 고른 레코드의 uuid를 근거 칸에 적는다. 서술 필드는 색깔로만 쓴다.
- 한계: 변수끼리 독립이라고 가정해 만들었고(상호작용 없음), gender 항목이 없고, 19세 미만이 없다. 태도나 UX 행동을 시뮬레이션하는 용도로 검증된 데이터라고 카드가 주장하지 않는다 — 결과물에 이 한계를 적는다.

## 5. 쓰지 않는 것

- 실제 인물의 이름·연락처·사진, 실제 사용자 데이터의 개인 식별 정보
- 건강 상태 자체 — 접근성 필요(「화면 낭독기를 쓴다」)로만 추상화한다
- 웃음거리가 되는 캐리커처, 집단에 대한 고정관념을 그대로 옮긴 말투

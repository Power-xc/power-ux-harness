# 화면 설계서 양식과 핸드오프 점검표

출처: 국내 화면설계서 관례(이랜서 블로그 2022, 요즘IT 2022, brunch @planbasic 2026 — 표지·개정 이력·화면 ID·번호 붙인 설명), Figma Help「Guide to Dev Mode」·「Name and organize components」, Figma Developer Docs「Structure your Figma file for better code」, Figma Blog「Introducing Specs」(2026). 양식은 이 저장소에서 정리했다.

## 1. 양식

```markdown
# 독서 노트 앱 — 구독 관리 화면 설계서

| 버전 | 날짜       | 작성   | 변경                                 |
| ---- | ---------- | ------ | ------------------------------------ |
| v1.2 | 2026-11-02 | 담당자 | SCR-SUB-03 버튼 문구 변경            |
| v1.1 | 2026-10-28 | 담당자 | SCR-SUB-02 해지 이유를 선택 사항으로 |

## SCR-SUB-03 구독 해지 확인

- 경로: 설정 > 구독 관리 > 해지하기
- 목적: 해지했을 때 무엇이 바뀌는지 이해하고 해지를 확정한다
- 진입: SCR-SUB-01 「해지하기」, SCR-SUB-02 「다음」
- 이탈: 「닫기」 → SCR-SUB-01 · 해지 성공 → SCR-SUB-04 · 실패 → 이 화면(인라인 오류)

### 영역

| 번호 | 컴포넌트              | 동작                                                | 상태                           | 문구                                                                      | 데이터                                                   |
| ---- | --------------------- | --------------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------- | -------------------------------------------------------- |
| ①    | 대화상자              | 열리면 제목으로 포커스                              | 기본                           | 제목 「구독을 해지할까요?」 · 본문 「해지해도 {만료일}까지 쓸 수 있어요」 | 만료일: 구독 정보의 다음 결제일 전날, 「11월 30일」 형식 |
| ②    | 버튼 2개(같은 크기)   | 「닫기」 → 대화상자 닫힘 · 「해지하기」 → 해지 요청 | 기본 · 누름 · 포커스 · 처리 중 | 「닫기」 · 「해지하기」                                                   | —                                                        |
| ③    | 로딩 버튼             | 요청 중 두 버튼 비활성, 중복 요청 막음              | 처리 중                        | —                                                                         | —                                                        |
| ④    | 스낵바(SCR-SUB-01 위) | 「되돌리기」 → 해지 취소 요청                       | 누르거나 닫을 때까지 유지      | 「구독을 해지했어요」 · 「되돌리기」                                      | 되돌리기는 다음 결제일 전까지                            |

### 화면 상태

| 상태    | 모습                                                                                    |
| ------- | --------------------------------------------------------------------------------------- |
| 처리 중 | ②의 「해지하기」가 로딩 버튼으로 바뀌고 두 버튼이 비활성                                |
| 오류    | 본문 아래 인라인 오류 「해지하지 못했어요. 잠시 뒤 다시 시도해 주세요」 + 「다시 시도」 |
| 끝      | SCR-SUB-04에서 남은 이용 기간과 「다시 구독하기」                                       |

### 모션

- 대화상자 등장 200ms 이즈 아웃(배경 어둡게 함께), 닫힘 150ms 이즈 인
- 움직임 줄이기 설정: 페이드만

### 접근성

- 열리면 제목으로 포커스, 포커스는 대화상자 안에서만 돈다, Esc로 닫는다
- 닫히면 SCR-SUB-01의 「해지하기」로 포커스가 돌아간다
- 버튼 터치 영역 44×44pt 이상(iOS) · 48×48dp 이상(Android) · 24×24px 이상(웹 최소)
- 해지 결과 스낵바는 `role="status"`로 알린다

### 이벤트

| 이벤트                | 시점                | 속성                      |
| --------------------- | ------------------- | ------------------------- |
| `cancel_confirm_view` | 대화상자 열림       | `plan`, `days_left`       |
| `cancel_complete`     | 해지 성공           | `plan`, `reason_selected` |
| `cancel_undo`         | 스낵바 「되돌리기」 | `plan`                    |

### 예외

- 결제 처리 중 해지 요청 → 「결제가 끝난 뒤 다시 시도해 주세요」
- 만료일을 불러오지 못함 → 본문에서 날짜를 빼고 「남은 기간은 구독 관리에서 볼 수 있어요」

### 완료 조건

- 「해지하기」를 두 번 눌러도 해지 요청은 한 번만 간다
- 해지 뒤 SCR-SUB-04에 남은 이용 기간이 날짜로 보인다
- 키보드만으로 열고, 해지하고, 닫을 수 있다

## 정해야 할 것

| 질문                    | 선택지                | 영향 화면     | 담당 |
| ----------------------- | --------------------- | ------------- | ---- |
| 남은 기간 환불을 하는가 | 환불 없음 / 일할 환불 | SCR-SUB-03·04 | 사업 |
```

## 2. 핸드오프 점검표

| 항목            | 기준                                                                                |
| --------------- | ----------------------------------------------------------------------------------- |
| 화면 ID         | 모든 화면에 고유 ID, 흐름도·화면 목록과 일치                                        |
| 컴포넌트        | 디자인 시스템 컴포넌트를 떼어 내지 않고 인스턴스로 사용, 표준 이름                  |
| 변수·토큰       | 색·간격·글자·모서리에 변수나 스타일 적용 — 숫자를 직접 박지 않음                    |
| 레이어 이름     | 의미 있는 이름(`CardContainer`), 자동 이름(`Frame 1268`) 없음                       |
| 오토 레이아웃   | 프레임 크기를 바꿔도 깨지지 않음                                                    |
| 상태 프레임     | 화면 상태와 컴포넌트 상태가 각각 프레임으로 있음                                    |
| 주석            | 화면에 안 보이는 동작·간격·데이터는 주석으로                                        |
| 개발 준비 표시  | 넘길 프레임을 Dev Mode의 Ready for dev로 표시                                       |
| 코드 연결       | Code Connect를 쓰면 컴포넌트를 코드 컴포넌트와 연결                                 |
| 문구            | 실제 문구, 자리표시 글(Lorem ipsum) 없음                                            |
| 에셋            | 내보내기 형식·배율 설정                                                             |
| 에이전트용 명세 | 코딩 에이전트에게 넘기면 이 설계서(마크다운)나 캔버스 위 명세 문서 링크를 함께 준다 |

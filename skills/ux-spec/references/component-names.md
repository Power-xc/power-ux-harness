# 컴포넌트 이름 대조표

설계서에는 왼쪽 열의 표준 이름을 쓴다. 팀의 디자인 시스템에 정해진 이름이 있으면 그 이름이 우선이고, 처음 등장할 때 괄호로 표준 이름을 붙인다.

출처: Google Material Design 3 컴포넌트 목록(2025 Expressive·2026 I/O 갱신 포함), Apple Human Interface Guidelines 컴포넌트 목록, 행정안전부 KRDS(Korea Design System) 컴포넌트 이름, The Component Gallery(component.gallery)의 별칭 정리, Material Symbols 아이콘 이름(google/material-design-icons 코드포인트 목록, 2026-11-03 확인). 「—」는 해당 체계에 같은 이름의 컴포넌트가 없거나 확인하지 못했다는 뜻이다.

## 1. 이름이 겹치는 곳 — 먼저 확인한다

| 말            | 문제                                                             | 설계서에 쓸 이름                              |
| ------------- | ---------------------------------------------------------------- | --------------------------------------------- |
| 팝업          | 대화상자·바텀시트·토스트·새 창을 모두 가리킨다                   | 대화상자 / 바텀시트 / 토스트 / 스낵바 중 하나 |
| 모달          | 성격(흐름을 막음)이지 컴포넌트가 아니다                          | 대화상자, 모달 바텀시트, 전체 화면 대화상자   |
| 내비게이션 바 | Material에서는 하단 탭, Apple에서는 화면 위쪽 막대               | 하단 탭 / 상단 앱 바                          |
| 스테퍼        | Apple에서는 수량 ± 컨트롤, 웹·공공 디자인 시스템에서는 진행 단계 | 수량 스테퍼 / 단계 표시                       |
| 토글          | 켜고 끄는 스위치와, 눌린 상태를 유지하는 토글 버튼이 다르다      | 스위치 / 토글 버튼                            |
| 탭            | 화면 위 보기 전환과 하단의 최상위 이동이 다르다                  | 상단 탭 / 하단 탭                             |

## 6. 아이콘만 있는 메뉴 버튼

모양에 붙은 별명은 기능 이름이 아니다. 설계서에는 기능으로 쓴 표준 이름을 적고 모양은 괄호에 별명으로 붙인다(예: 더 보기 메뉴(케밥)). 팀 밖에서도 통하는 별명은 햄버거·케밥 정도다.

| 모양                    | 별명      | 흔한 기능 → 설계서에 쓸 이름                  | Material Symbols |
| ----------------------- | --------- | --------------------------------------------- | ---------------- |
| 가로줄 셋               | 햄버거    | 내비게이션 드로어 열기                        | `menu`           |
| 세로 점 셋              | 케밥      | 더 보기 메뉴                                  | `more_vert`      |
| 가로 점 셋              | 미트볼    | 더 보기 메뉴                                  | `more_horiz`     |
| 점 아홉(3×3)            | 와플      | 앱 전환·서비스 모음                           | —                |
| 네모 아홉(3×3)          | 벤토      | 앱 전환·서비스 모음                           | `apps`           |
| 가운데로 짧아지는 줄 셋 | 도너      | 필터                                          | `filter_list`    |
| 가로줄 둘               | 베지 버거 | 메뉴, 또는 끌어서 옮기는 손잡이 — 뜻이 갈린다 | `drag_handle`    |
| 왼쪽 정렬로 짧아지는 줄 | 계단      | 정렬                                          | `sort`           |
| 손잡이가 달린 줄        | 슬라이더  | 필터·세부 조정                                | `tune`           |

- 아이콘만 있는 버튼에는 기능을 말하는 접근 가능한 이름을 단다(「더 보기」, 「필터」 — WCAG 4.1.2). 「케밥」, 「메뉴 아이콘」은 이름이 아니다.
- 한 제품 안에서 같은 기능에 케밥과 미트볼을 섞어 쓰지 않는다.
- 주요 메뉴를 햄버거 뒤에 숨기기로 했으면 설계서에 이유를 적는다. 숨긴 메뉴는 덜 쓰이고 찾는 데 오래 걸린다(`ux-review`의 패턴 쓰임 대조표 4절).

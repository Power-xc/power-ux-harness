# 맥락 사례 — 규모·시장

출처: 아래 출처 표의 공식 블로그·뉴스룸·도움말·규제 기관 문서(2018–2025년). 원문을 옮기지 않고 요약했으며 모두 2026-11-02에 직접 열어 확인했다. 양식과 수록 기준은 [`../casebook.md`](../casebook.md)를 따른다.

이 파일의 사례는 같은 문제를 **규모·사업 방식·시장과 문화·규제**가 달라서 다르게 푼 경우다. 정답을 바꾸는 맥락 칸은 다섯 가지다. (1) 사용자층이 바뀐 것 — 직장인에서 학생·가정으로, 숙련자에서 설정을 찾지 않는 사람으로. (2) 퍼지는 속도 — 한 번의 행동이 몇 명에게 닿는가. (3) 사업 방식 — 확산이 성장의 엔진인 단계인가, 수익화 단계인가. (4) 시장과 문화 — 집단 대화나 숫자 노출이 사회적 부담이 되는 곳. (5) 규제 변화 — 같은 화면이 지역마다 다른 기본값을 갖게 만드는 힘. 본 화면은 직접 보지 않았으므로 모든 해법은 `reported`다. 현재 상태를 확인하지 못한 사례는 사례 안에 따로 적었다.

### SM-01 쓰는 사람이 학교와 가정으로 넓어지자, 입장 통제를 「선택」에서 「기본」으로

| 해법        | Zoom — 2020-04 기준 대기실을 교육·무료(Basic)·1인 Pro 계정에서, 회의 암호를 Basic·1인 Pro·K-12를 포함한 대부분의 고객에서 기본으로 켰고, 교육 고객은 화면 공유 기본을 호스트만으로 뒀다 (S2). K-12 프로그램 교육 사용자의 대기실 기본 켜짐과 교사만 공유할 수 있는 기본값, 관리자·교사용 가이드도 따로 냈다 (`reported`, S1). 대기실은 호스트가 진행 중에도 켤 수 있다 (S2).                            |

| 칸          | 내용                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상황        | 한 번 받은 메시지를 여러 사람·방으로 즉시 다시 보낼 수 있어 소문과 연쇄 메시지가 빠르게 퍼진다.                                                                                                                                                                                                                                                                                                                                   |

### SM-03 단체방을 나가는 일이 부담인 곳에서는, 퇴장을 알리지 않는 선택지를 만들었다

| 칸          | 내용                                                                                                                                                                                                                                                                                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상황        | 단체 채팅방에서 나가면 「OOO님이 나갔습니다」가 모두에게 보인다. 조용해졌거나 나갈 때를 놓친 방에서 이 표시가 부담이 된다.                                                                                                                                                                                                                                                   |
| 해법        | 카카오톡 — 2023-05 v10.2.0 실험실 옵션으로 도입해 켜고 나가면 퇴장 문구가 다른 참여자에게 보이지 않는다. 그룹 채팅방에만 적용 (S8). 2023-08 v10.3.0에서 정식 반영, 실험실 3주 동안 약 200만 명이 켰고 약 3개월 검토했다고 밝혔다 (S9). 나가지 않고 조용한 방을 보관함으로 숨기는 기능도 실험실에 함께 들어갔다 (S9) (`reported`).                                            |
| 대조        | 같은 서비스의 이전 방식 — 퇴장 문구가 항상 보였다. 2022년 말에는 유료 구독(톡서랍 플러스) 이용자가 개설하는 팀 채팅방에 먼저 도입해 일반 단체방 이용자의 불만이 있었고, 카카오는 일반 단체방 확대를 준비 중이라고 밝혔다. 3인 이상 대화 서비스에 알리지 않고 나갈 수 있는 기술 조치를 요구하고 어기면 과태료를 매기는 법안도 발의됐다 (S10, 법안의 통과 여부는 열지 못했다). |

### SM-08 습관 앱에서 하루 빠짐이 이탈로 이어지지 않도록, 연속 기록에 예외를 설계했다

## 이 파일에서 뽑은 원리

- 사용자층이 설정을 찾아 켤 수 없는 쪽으로 넓어지면, 보호는 옵션이 아니라 기본값이다 (SM-01).
- 퍼지는 속도가 피해를 키우면 내용을 판정하기 전에 한 번에 닿는 폭에 상한을 건다 (SM-02).
- 나가거나 숨기는 행동이 사회적 비용이면 당사자가 알림과 노출을 정할 수 있게 하고, 숫자 효용이 갈리면 선택으로 둔다 (SM-03, SM-04).
- 사업이 확산 단계에서 수익화 단계로 넘어가 제한을 걸 때는 합법적 예외를 제품 안에 정식 경로로 둔다 (SM-06, SM-08).
- 규제가 같은 화면의 기본값을 지역마다 다르게 만든다. 지역을 나눠 설계하고 규제 일정을 맥락 카드에 적는다 (SM-05, SM-07).

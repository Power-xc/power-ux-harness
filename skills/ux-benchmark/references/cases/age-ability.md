# 맥락 사례 — 나이·능력

이 파일은 사용자의 나이와 능력이 정답을 바꾼 사례를 모은다. 나이는 그 자체로 쓰지 않고 설계에 쓸 수 있는 칸으로 풀어 읽는다. 디지털 숙련도(앱 없이도 끝낼 수 있어야 하는가), 시력·손의 정밀도·인지 부담(화면을 얼마나 덜어 내야 하는가), 사기와 부적절한 콘텐츠에 노출되는 정도(기본값을 어디에 두는가), 보호자와 대리 사용(누가 설정하고 누가 승인하는가)이 그 칸이다. 양식과 수록 기준은 [`../casebook.md`](../casebook.md)를 따른다. 모든 사례의 화면은 직접 보지 않았으므로 증거 수준은 `reported`다. 확인일은 모두 2026-11-02이며 출처를 모두 다시 열어 대조했다. 출처가 언론뿐인 사실은 「언론」으로 적었고, 출처에 없는 작성자의 판단은 「해석:」으로 표시했다. 「가져갈 원리」와 「안 맞는 곳」은 작성자의 제안이다.

### AA-01 Apple Watch는 나이를 입력해 두면 55세 이상에게 낙상 감지를 자동으로 켠다

| 칸          | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상황        | 심하게 넘어진 뒤 스스로 도움을 부르지 못하는 경우와, 활동적인 사용자의 움직임을 낙상으로 오인하는 경우를 한 기능이 함께 다룬다.                                                                                                                                                                                                                                                                                                                                                                                                           |
| 해법        | Apple Watch — 설정이나 건강 앱에 나이를 입력했고 55세 이상이면 낙상 감지가 자동으로 켜진다. 이 기능은 18세 이상에게만 제공된다(`reported`, S1). 켜 둔 뒤에는 「항상」과 「운동 중에만」을 고를 수 있다(S1). 55세 미만의 기본값은 S1에 없고, S2는 watchOS 8.1 이상으로 새로 설정한 시계에서 18\~55세에게 「운동 중에만」이 자동으로 켜진다고 적는다. 이전 버전에서 업그레이드한 시계는 직접 켜야 한다(S2). S1은 55세 이상, S2는 18\~55세로 적어 경계가 겹쳐 보이므로, 인용은 「나이를 입력했고 55세 이상이면 자동으로 켜진다」까지만 한다. |
| 대조        | 같은 기능의 55세 미만 값 — 새로 설정한 시계에서는 운동 중에만 켜지고, 사용자가 항상 켜짐으로 바꿀 수 있다(S1, S2). 쓰러진 뒤 약 1분 움직임이 없으면 30초 카운트다운을 시작하고, 그 사이에 취소하지 않으면 긴급 전화를 건다. 움직이고 있으면 자동으로 전화하지 않고 사용자의 응답을 기다린다(`reported`, S1).                                                                                                                                                                                                                              |
| 결정적 맥락 | 사용자(연령)와 위험. 출처로 확인되는 것은 나이 입력값과 55세 기준으로 기본값이 갈린다는 점이다(S1). Apple은 55세 기준의 이유를 이 문서에서 밝히지 않았다(S1). 해석: 연령에 따라 낙상 위험과 도움 요청 능력이 다르고, 못 불렀을 때의 피해가 오경보의 불편보다 크다고 보아 기본값을 갈랐다.                                                                                                                                                                                                                                                 |

Apple은 의료 ID와 건강 프로필의 나이가 맞는지 확인하라고 안내한다(S1). 나이를 입력하지 않으면 자동 켜짐 조건에 닿지 않는다(S1). 자동 긴급 전화는 손목 감지가 켜져 있어야 한다(S1). 오경보는 카운트다운과 취소로 줄일 뿐 없애지 못한다(S1).                                                                                                                                                                                                                                                                        |

| 상황        | 같은 어린이 앱을 4세 이하와 12세가 함께 쓴다. 보여 줄 콘텐츠와 자유도가 나이에 따라 크게 다르고, 고르는 사람은 아이가 아니라 보호자다.                                                                                                                                                                                                                                                                                                                                  |
| 해법        | YouTube Kids — 콘텐츠 단계를 Preschool(4세 이하), Younger(5\~8세), Older(9\~12세)로 두고(S18), 보호자가 영상·채널·모음을 직접 고르는 「직접 승인」도 제공한다(`reported`, S19, S24). 직접 승인하면 아이는 승인한 것만 볼 수 있고 검색할 수 없으며(S24), 이 설정은 YouTube Kids 앱에서 고른다(S19). 검색을 끄면 YouTube Kids가 확인한 영상·채널로 제한되고 해당 프로필의 시청·검색 기록이 지워지며 추천이 초기화된다. 앱 설정은 암호(또는 곱셈 문제)를 거쳐 바꾼다(S19). |
| 대조        | 같은 앱 안의 세 가지 자유도 — 단계만 고르기, 검색 끄기, 직접 승인. 해석: 보호자가 아이 성장에 맞춰 풀어 가는 구조다.                                                                                                                                                                                                                                                                                                                                                    |
| 결정적 맥락 | 해석: 사용자(아이의 읽기·판단 능력이 나이에 따라 다르다)와 함께 쓰는 사람(보호자가 설정하고 책임진다), 위험(부적절한 콘텐츠에의 노출)이 설계를 갈랐다. 출처로 확인되는 것은 단계가 나이 구간으로 나뉘고 설정을 보호자가 바꾼다는 점이다(S18, S19).                                                                                                                                                                                                                      |
| 대가        | 단계를 정하는 일이 보호자 몫이다. 검색을 끄면 기록이 사라져 추천이 처음부터 다시 쌓인다(S19).                                                                                                                                                                                                                                                                                                                                                                           |
| 가져갈 원리 | 어린 사용자의 안전은 나이 한 칸이 아니라, 단계·검색 여부·직접 승인처럼 보호자가 조절하는 여러 칸으로 풀어 준다.                                                                                                                                                                                                                                                                                                                                                         |
| 안 맞는 곳  | 보호자와 연결할 방법이 없는 서비스, 단계를 채울 만큼 콘텐츠가 많지 않은 소규모 서비스, 성인 대상 서비스.                                                                                                                                                                                                                                                                                                                                                                |
| 시점        | 현행 도움말 기준(확인일 2026-11-02). 도입 연월은 이번에 열어 본 출처에서 확인하지 못했다.                                                                                                                                                                                                                                                                                                                                                                               |

### AA-08 10대 계정은 안전 쪽을 기본값으로 두고, 풀려면 16세 미만은 보호자 승인을 받게 했다

| 칸          | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 상황        | 10대는 낯선 사람의 접촉, 민감한 콘텐츠, 밤늦은 사용에 노출되기 쉽고, 스스로 설정을 찾아 바꾸는 일에 기대기 어렵다.                                                                                                                                                                                                                                                                                                                                                     |
| 해법        | Instagram 10대 계정 — 청소년을 자동으로 이 계정에 둔다(기존 포함). 16세 미만(기존·신규)과 가입하는 18세 미만은 비공개가 기본이고, 메시지는 이미 이어진 사람에게서만 받는다. 2024-09 발표 때 민감한 콘텐츠는 가장 엄격하게 두고, 하루 60분 뒤 앱을 나가라는 알림을 보내며, 밤 10시\~오전 7시 수면 모드는 알림을 끄고 DM에 자동 답장한다. 16세 미만이 덜 엄격한 설정으로 바꾸려면 보호자 승인이 필요하고, 16\~17세 보호자는 감독을 켜서 승인할 수 있다(`reported`, S20). |
| 대조        | 같은 서비스 안의 연령 구간 — 16세 미만은 보호자 승인, 16\~17세는 보호자가 감독을 켠 경우에만 승인 구조가 작동한다(S20). 2025년 4월에는 16세 미만이 보호자 허락 없이 라이브를 할 수 없게 했다(S21). 2025-10-14 새 글은 18세 미만 10대를 자동으로 13+ 콘텐츠 설정에 두고 보호자 허락 없이는 벗어나지 못하게 한다고 밝혔다. 적용은 미국·영국·호주·캐나다부터 순차이고 전 세계 확대는 예정이다(S23).                                                                       |
| 결정적 맥락 | 사용자(연령 구간)와 위험(낯선 사람 간 접촉, 민감 콘텐츠), 함께 쓰는 사람(보호자 승인 경로).                                                                                                                                                                                                                                                                                                                                                                            |
| 대가        | 연령 정보가 틀리면 보호가 빠진다. 2025년 3월 27일 갱신에서 Meta는 성인 생일 계정의 연령 확인 요구가 잘 작동하지 않았다며 접고, 10대로 의심되는 계정을 생일과 무관하게 10대 계정 설정에 두는 방식을 시험한다고 밝혔다(2024-09 글은 미국 시험을 예고, S21). 보호자가 승인 구조를 켜지 않은 16\~17세는 스스로 설정을 바꿀 수 있다(S20). 해석: 청소년 입장에서는 자율성이 줄어든다.                                                                                        |
| 가져갈 원리 | 위험이 큰 설정은 안전 쪽을 기본값으로 두고, 풀 때는 마찰이 큰 경로(보호자 승인)를 거치게 한다. 연령 구간마다 풀 수 있는 주체를 다르게 둔다.                                                                                                                                                                                                                                                                                                                            |
| 안 맞는 곳  | 보호자와 계정을 연결할 수 없는 서비스, 연령을 확인할 방법이 없는 서비스, 기본값이 안전 쪽이면 핵심 가치가 사라지는 서비스.                                                                                                                                                                                                                                                                                                                                             |
| 시점        | 2024-09-17 발표(S20), 2025-06-11 인스타그램을 쓸 수 있는 모든 나라로 확대(S21), 2025-10-14 13+ 콘텐츠 설정 발표(S23, 2026-05-07 최종 갱신). S20 머리에는 2025-10-22가 표시되나 갱신 내용은 페이지에 적혀 있지 않다. 한국 계정의 현재 값은 확인하지 못했다.                                                                                                                                                                                                             |

## 이 파일에서 뽑은 원리

- 나이는 기본값의 출발점으로 쓰고, 끄고 켜는 선택은 열어 둔다(AA-01, AA-05). 나이 라벨은 낙인이 되므로 이름은 숙련도로 짓는다.
- 속도·순서 경쟁에서는 줄 순서와 제한 시간과 대신 쓰는 경로가 화면 개선보다 크다. 열어 준 만큼 오용 방지 장치를 둔다(AA-02).
- 디지털 접수와 기기에는 사람이 받는 경로를 남긴다. 규모가 작은 곳은 기기 대신 사람으로 갈음하게 하되 독립 이용의 한계를 같이 적는다(AA-03, AA-04).
- 인지 부담은 기능 수를 줄여 푼다. 줄이는 일은 곁의 사람이 맡고, 쓰는 화면과 설정하는 화면을 나눈다(AA-06).
- 어린 사용자는 위험이 큰 값을 안전 쪽 기본으로 두고, 풀 때 보호자를 거치게 하며, 나이는 한 칸이 아니라 여러 칸(단계·검색·승인)으로 푼다(AA-07, AA-08).
